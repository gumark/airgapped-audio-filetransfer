How It Works

1

File → Audio

The transmitter encodes your file into audio frequencies using FSK modulation

→
2

Speaker → Air → Mic

Sound carries the payload between the two machines

→
3

Audio → File

The receiver demodulates the audio and reconstructs the original file

Quick start

Set up two isolated machines.

Use one computer as the transmitter and another as the receiver. Choose a file on the first, allow microphone access on the second, then place the speaker near the microphone.
